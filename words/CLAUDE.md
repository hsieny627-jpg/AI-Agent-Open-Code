# 單字小故事網頁 — 規格（接手的 Claude 先讀完再動手）

使用者是國小英語教師。**這份規格是使用者反覆修正後的結果，不要自行「優化」。**

## 這是什麼

一個單字一個獨立網頁，`words/<單字>.html`，單檔、零外部相依。
資料來源是專案根目錄 `family-time-machine-ipad.html` 裡的 `D` 陣列（17 個家人單字）。

## 四幕結構（固定，不要增減）

| 幕 | 內容 |
|---|---|
| ① | 中文意思 ＋ 秒懂圖示（大 emoji） |
| ② 以前 | 單字最早的樣貌 ＋ 同一個圖示（圖示就是意思，**不加說明文字**） |
| ③ 為什麼 | 演變**原因**用動畫呈現。定案文案：**單字搬家，發音不同**（🏠 →🚶💬→ 🏡） |
| ④ 現在 | 今天的單字 ＋ 一句秒懂收尾 |

## 絕對不可違反

1. **嚴禁交代單字演變過程**。不可做字母逐格變形（brōþor→brothor→brother 這種）。
   學生連現在的單字都背不起來，看拼字怎麼變只會覺得英文更難。
   只給「以前的樣子」和「現在的樣子」兩張快照，中間不畫。
2. **不新增任何字源解釋**。所有文字只能從該單字現有的 `story` / `hook` / `q` / `a` 欄位濃縮。
3. **一頁只講這一個單字**，不可提到別的單字（例如 father 頁不可出現 grandfather）。
4. **不講學生用不到的東西**。拉丁文、語言分支、共同祖先這類內容已被移除——
   國小學生一輩子用不到，記憶效益是零。
5. **最少的字**。一幕一句話，一句話講一件事。看不懂就是失敗。
6. **不自動換頁**。左右兩邊各一條翻頁箭頭（`.nav`，整條邊都可按，最小 68px 寬），
   老師和學生自己控速。鍵盤 ← → 也要能用。
7. **字體一律 Andika**，而且**字體檔要隨檔案走**（`words/fonts/andika-*.woff2`），
   離線也必須是 Andika，不可只靠 Google Fonts 連線。
   Andika 只有 400 / 700 兩種粗細，**字重不可寫 800 或 900**（瀏覽器會硬加粗，糊掉）。

## 版面

- 全黑底 `#000`；配色沿用：強調 `#9FB4C8`、正文 `#D8D3C5`、白 `#F2F2F2`、
  按鈕底 `#1E1E1E`、框線 `#4A4A4A`
- 尺寸全用 `clamp()` ＋ `vh/vw` 雙限，1024×768 與直式 820×1180 都不得溢出
- `#stage` 左右 padding 必須大於 `.nav` 寬度，否則內容會被箭頭壓到
- `prefers-reduced-motion` 開啟時關掉所有動畫（`.reduce`），但四幕仍要能手動翻

## 驗證（改完一定要做，不可只寫完就回報）

```bash
# JS 語法
perl -0777 -ne 'if(/<script>(.*?)<\/script>/s){print $1}' words/<單字>.html > /tmp/a.js && node --check /tmp/a.js
```

用 Playwright（`/opt/node22/lib/node_modules/playwright`，Chromium 已內建）**量測**，不要目視：
- `offline:true` 開檔，確認 Andika 仍生效（`measureText` 與 sans-serif 不同 = 有載到）
- 逐幕點 `#next` 截圖，確認四幕內容、箭頭首尾停用、`scrollWidth` 未溢出
- 停 6 秒確認**沒有**自動換頁
- 幕③ 確認行人沒有壓到右邊房子（比較 `.trav` 與 `.move .r` 的 `getBoundingClientRect`）

## 省額度的做法

- **不要每改一次就截圖給使用者看**。發佈成 Artifact 網址，使用者自己重新整理。
- **樣板定案後才批次做其餘單字**，一次做完比一個一個做便宜很多。
- 使用者一次講完所有要改的點，比分多輪講便宜。
- 這個資料夾的規格就是為了讓新對話不必重新問一遍——**開新對話時它會自動載入**。
