# Codex 基本功 — 主題總覽

## 主題一句話
GPT Codex 是一款便宜好上手的 AI 助手（Agent），本系列手把手教你從安裝、設定、接上 GitHub 與 Obsidian、串接資料庫，到學會「開工／收工／專案初始化」的工作模式，讓老師也能用它備課、抓資料、做教材，不再事事自己動手。

## 對老師最有用的重點
- **便宜又大碗**：Codex 用 ChatGPT 帳號（20 美金方案）就能用，能力與 Claude 接近但便宜很多，適合預算有限的老師。
- **自動上網抓資料**：內建瀏覽器（Computer Use）能自己上網下載「國中會考歷屆試題」到資料夾，老師備題庫、備教材省下大量時間。
- **Skill 就是「說明書」**：只要事情有固定流程和成品，就能做成技能，一次吩咐做完（例如分析歷屆試題、輸出重點與應考策略圖表），一次講完最省用量。
- **開工／收工／專案初始化**：建立一致的工作模式後，資料放在 Obsidian、GitHub、Firebase，換任何一家 Agent 都能接續同一個專案，不怕被綁住。
- **Google 雲端＋Obsidian＋GitHub**：把筆記、程式、資料庫都「搬家」到雲端，AI 就能跨專案、跨對話持續幫你工作，等於老師的數位第二大腦。
