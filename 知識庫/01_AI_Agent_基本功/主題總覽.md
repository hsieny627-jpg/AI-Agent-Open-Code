- **一句話用法**：直接把工具清單裡那一欄「一句話」複製貼給任何 Agent（Claude Code / Codex / Antigravity / OpenCode），它就會幫你做。

## 對老師最有用的重點
- **先建立觀念再學工具**：按「AI Agent 基本功」EP01→EP07 的順序看完，跨過門檻後效率可提升 5~10 倍，之後任何 Agent（Claude Code、Codex、AntiGravity、OpenCode）都聽得懂。
- **權限設定要安全**：新手建議開「半自動（待核准）」，既有效率又不會讓 AI 擅自改錯或刪錯檔案；全自動有風險，老手熟悉工作流後再用。
- **必學一招「複製路徑」**：在檔案上按右鍵選「複製路徑」（Ctrl+Shift+C）丟給 Agent，它就能精準讀檔，省 Token 又不會找不到檔案。
- **用自然語言操控所有工具**：透過 MCP、連接器等通道把 Padlet、Gmail、NotebookLM 等接到 Agent，以後不用再學每套工具的操作介面，直接用中文下指令即可。
- **教材製作全面自動化**：台語教材（講義、考卷、語音、影片、互動遊戲）、三種簡報（圖片式、可編輯式、HTML 互動式）、甚至直接產出影片，都能交給 Agent 一鍵完成，大幅省下備課時間。
- **換電腦／多台協作無痛**：用雲端硬碟放專案、用 chezmoi 同步技能與設定，同一專案可在不同 Agent、不同電腦間接力完成。
- **EP03 核心口訣**：四步迴圈「讀進來 → 處理 → 抓資料 → 產出去」，一句話定調「**生成式 AI 動嘴，Agent 動手**」；安全三原則「半自動為主、限制在專案目錄、來路不明的工具別亂裝」。
- **EP03 工具清單最實用**：套印獎狀、出考卷（學生卷／教師卷分開）、成績分析、PDF 合併浮水印、QR code、課本轉 Markdown，通通「一句話」搞定；用完工具清單再決定要不要裝選用工具。
